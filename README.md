# Автоматизированное тестирование Ростелеком ID

## Тестируемый ресурс

https://b2c.passport.rt.ru/

## Цель проекта

Провести функциональное тестирование сервиса Ростелеком ID, разработать тест-кейсы и автоматизировать проверки основных функций авторизации и восстановления пароля.

## Что проверяется

В проекте проверяются:

- отображение формы авторизации;
- авторизация по номеру телефона;
- авторизация по электронной почте;
- авторизация по логину;
- авторизация по лицевому счёту;
- переключение типа авторизации;
- авторизация по временному коду;
- ввод кода подтверждения;
- обработка некорректного кода;
- форма восстановления пароля;
- требования к паролю;
- ввод допустимых символов в пароль.

Всего разработано 20 автоматизированных тестов.

## Технологии и инструменты

### Python 3

Используется как основной язык программирования для написания автоматизированных тестов.

### PyTest

Используется для организации и запуска автоматизированных тестов, а также для получения результатов их выполнения.

### Selenium

Используется для автоматизации взаимодействия с веб-интерфейсом: открытия страницы, поиска элементов, выбора вкладок, ввода данных и нажатия кнопок.

### webdriver-manager

Используется для упрощения работы с драйвером браузера Chrome.

### Почему выбраны эти инструменты

Связка Python, PyTest и Selenium подходит для автоматизации функционального тестирования веб-приложения. Selenium позволяет выполнять действия пользователя в браузере, Python используется для реализации тестовой логики, а PyTest обеспечивает удобный запуск и получение результатов тестирования.
