# Автоматизированное тестирование Ростелеком ID

## Тестируемый сайт

https://b2c.passport.rt.ru/

## Цель проекта

Автоматизация тестирования формы авторизации Ростелеком ID.

## Используемые технологии

- Python 3
- PyTest
- Selenium

## Автоматизированные проверки

В проекте реализовано 20 автоматизированных тестов:

- отображение формы авторизации;
- выбор авторизации по телефону;
- вкладка электронной почты;
- вкладка логина;
- вкладка лицевого счёта;
- наличие полей авторизации;
- ввод электронной почты;
- авторизация по временному коду;
- ввод шестизначного кода;
- проверка кнопки получения кода;
- проверка некорректного кода;
- восстановление пароля;
- проверка минимальной длины пароля;
- проверка заглавной буквы;
- ввод пароля с заглавной буквой;
- проверка латинских символов;
- ввод цифр в пароле.

## Тест-дизайн

Использованы:

- классы эквивалентности;
- анализ граничных значений.
